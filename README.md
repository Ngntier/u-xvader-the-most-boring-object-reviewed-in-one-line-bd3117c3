# The Most Boring Object, Reviewed in One Line

A make.fun entry for the competition [The Most Boring Object, Reviewed in One Line](https://make.fun/competitions/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3) on [make.fun](https://make.fun).

The program (`main.py`) writes a single funny, true one-line review of a
genuinely boring everyday object to `entry.txt`. The review is at most 200
characters and the joke comes from a real, recognisable detail of the
object itself: the thing whose whole job is drying is somehow always the
dampest thing in the kitchen.

## Run

```sh
python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
